# KKN Cigending 2026 — Website Presentasi

Website presentasi interaktif untuk KKN Reguler Universitas Muhammadiyah Bandung, Kelurahan Cigending.

## Struktur GitHub Pages

Upload **isi folder ini** ke root repository GitHub, bukan folder induknya:

```text
repository/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── logo-umb.png
    ├── logo-cigending-1.png
    ├── logo-cigending-2.png
    ├── logo-cigending-3.png
    └── ...foto...
```

Pastikan `index.html` berada langsung di root repository dan folder `assets` berada sejajar dengannya.

## Data ATS

## Catatan
Website tidak menampilkan NIK, KK, atau identitas rinci anak untuk menjaga privasi. Grafik menggunakan data agregat hasil verifikasi.

Tidak membutuhkan server atau database. Bisa dibuka langsung dengan `index.html` dan dipublikasikan melalui GitHub Pages.
